
# Churrasco

## Configuração Inicial

### 1. Executar o Código SQL
Importe o arquivo SQL do banco de dados antes de iniciar a aplicação.

### 2. Iniciar o Servidor PHP
Execute o seguinte comando no terminal:

```bash
php -S localhost:9000
```

Acesse a aplicação em `http://localhost:9000`
